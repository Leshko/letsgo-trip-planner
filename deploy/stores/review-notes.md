# Notes for Apple and Google review

## Sign-in for the reviewer (both stores)
LetsGo trips are private, so reviewers need an invite code to see a trip.
Before each submission, create a demo trip on the server with trip dates that
include the review week, add a few ideas, a plan for today and a wall post, and
put its invite code here:

> Demo: open the app, tap "I have a code", enter **XXXXXX**, type any
> name. The trip is set to today's dates, so trip mode and the family map are
> active. No email or password is needed.

## Background location (Apple guideline 2.5.4 / 5.1.1, Google Play location policy)
Use this text for Apple's review notes and Google's "Location permissions" and
"Foreground service: location" declarations:

> LetsGo Together has an optional family map for the days of a family trip
> (for example, finding each other at a theme park). Location is only used
> after the person turns on "Share my location" on the map screen, which
> explains what is shared and with whom. It is only available during the
> trip's dates, it keeps working while the app is in the background so family
> members can still find each other, and it switches off automatically at
> midnight after the trip's last day, when stored locations are deleted. On
> Android a persistent notification ("Sharing your location with the family")
> is shown the whole time; on iPhone the system location indicator is shown.
> Only the person's latest position is stored and only members of that trip
> can see it. The person can switch it off at any time.

Google also asks for a short video of the feature. Record on an Android phone
or emulator: open the trip → Map → turn on "Share my location" → read the
explanation → allow location → the pin appears → leave the app (notification
shows) → open the app → switch it off.

## Notifications
Notifications are optional, turned on from the profile screen, and only cover
activity in the person's own trips (new ideas, votes, comments, plan changes,
photos, new members). No marketing notifications.
